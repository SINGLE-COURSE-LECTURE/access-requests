# access-requests — ITEMS 게임 권한 요청함

학생이 강의 저장소를 볼 권한이 없을 때, 게임이 이 저장소에 **이슈로 요청**을 올립니다.
강사는 게임 안의 「요청함」에서 확인하고 승인 · 거절합니다. 직접 이슈를 쓰지 않아도 됩니다.

- 요청 이슈에는 GitHub 계정 · 과목 · 수업 코드 · 이름(또는 별명)만 적힙니다. 이메일 · 연락처는 적지 마세요.
- 이 저장소는 공개입니다 — 누구나 요청을 볼 수 있습니다.
- 라벨: `권한 요청` · `대기` → `승인`(조직 초대를 보냄) 또는 `거절`(사유는 댓글)
